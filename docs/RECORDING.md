# Recording the demo (≈ 4:30)

Open `http://localhost:5173/?record=1&lang=en` at 1920×1080. `?record=1` hides the stage bar and the Inspector's dev buttons. Add `&lang=zh` for 中文.
Autoplay types each user message at about 35 characters a second, so you only narrate. Keys work when no field has focus:
**Space** play/pause · **→** next step (while paused) · **R** reset · **1–6** play scenario · **A** attack variant · **I** Inspector (phone/tablet).

| Time | Key | Scenario | Narrate |
|---|---|---|---|
| 0:00 | `1` | S1 Upload and understand | Sample policy is read, the annual limit is flagged at 62%, the user corrects it, then asks about dengue. Show the Pipeline filling, then click a citation chip and **How I know this** (Evidence tab). |
| 1:00 | `2` | S2 Compare with a judge | Needs captured from memory, one follow-up. Two advocates and a judge, run in parallel. The cheaper plan is not the winner. Drag the worked-example slider. Handoff preview with masked data. |
| 2:00 | `3` | S3 Claim end to end | Pre-screen with dates, checklist 3 / 5, one inconsistency fixed, submit confirmation card (T3 tool), **Advance 3 days** push, plain-words delay explanation. |
| 3:15 | `4` | S4 Hidden instruction | Safety tab: instruction flagged on p.3, intent mismatch denied, payout account untouched. |
| 3:45 | `5` | S5 Over-reach | Three refusals with reason codes: payout change, someone else's policy, staff impersonation. |
| 4:10 | `6` | S6 Fallback and handoff | Code-switched question, correction re-plan, "buy me Bitcoin" fallback, consent flow. |

Export the evidence pack from the stage bar (not in record mode): **JSON** downloads the trace, **PNG** snapshots the screen. In the Inspector, **Copy trace** puts the JSON on the clipboard.
